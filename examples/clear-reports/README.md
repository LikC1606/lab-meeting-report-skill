# 更清楚的组会报告示例

所有原始材料均来自仓库中的合成案例，项目与论文都是虚构的。以下报告是本次编辑编写的输出参考，不是独立 Agent 行为评测结果，也不代表真实用户验证。

| 场景 | 原始材料 | 新版输出参考 | 想改善什么 |
|---|---|---|---|
| 实验进展 | [散记](../weekly-summary/weekly-notes.md)、[结果](../weekly-summary/results.csv)、[论文笔记](../weekly-summary/paper-notes.md) | [报告](progress.md) | 先说明结论，把对照、失败与资源选择讲清楚 |
| 论文分享 | [输入](../journal-club/input-notes.md)、[论文笔记](../journal-club/papers/synthetic-retrieval-notes.md) | [报告](journal-club.md) | 解释问题、方法、证据，不用满屏未知元数据 |
| 进展与文献 | [输入](../mixed/input-notes.md)、[结果](../mixed/results/current_experiment.csv)、[论文笔记](../mixed/papers/synthetic-balanced-retrieval.md) | [报告](mixed.md) | 解释可比边界，并区分建议方案与已完成实验 |

检查重点：主要数字与原始材料一致；负面结果和阻塞仍可见；来源按段落或表格归组；没有编造实验结果、机制、会议决定、负责人或截止日期。混合案例中明确请求了实验建议，因此报告包含标注为建议的设计。
